## Key gaps

Focusing on **core EA-tool admin parity** (excluding PLANV4-deferred items):

- **Meta-model configuration is the dominant gap.** LeanIX's entire admin value proposition is a fully configurable meta model: create custom fact-sheet types (#23), add custom typed fields with keys/renderers/search/filter/view flags (#19), create custom relations with multiplicity and fields-on-relations (#20), define subtypes (#22), and drive visibility with conditional attributes (#21). VantageMap's data model is fixed in code (12 types, 35 relation types, fixed subtype enums) with only a `customFields` jsonb escape hatch and **no admin UI**. This is the single largest area of missing admin surface (all L effort).
- **Granular, configurable permissions (#25, #26).** LeanIX configures CRUD permissions per field/relation per non-admin role, with subscription-type and tag-based overrides. VantageMap RBAC is coarse role-level (Viewer/Member/Admin → view/create/edit/delete/manage) with no per-field or per-type matrix.
- **Custom KPIs & Metrics (#37, #39).** LeanIX lets admins build absolute/percentage KPIs (COUNT/SUM/AVG, filters, trend, historical values) and store time-series metrics for dashboards. VantageMap ships a fixed report set (`src/lib/reports.ts`) with no user-defined KPI builder or metrics store.
- **Dashboards & Workspace Views config (#31, #45).** No admin control over predefined/default/template dashboards, external-content embedding, or role-scoped workspace views.
- **Subscription-roles & quality-seal configurability (#27, #50).** VantageMap has the underlying subscription types and quality-seal state machine, but both are hard-coded — no admin to define named subscription roles scoped to fact-sheet types, or to configure quality-seal states/permissions per type.
- **Workspace-general settings (#11, #12, #16).** Currency, fiscal year, idle timeout, quick-search mode, subscription mode/privacy, and maintenance mode are all admin-configurable in LeanIX and absent in VantageMap.

**Strong equivalence areas:** user administration (#48), technical users / API tokens (#49), tagging admin incl. tag modes (#10, #30), and subscription types (#28) are genuinely at parity.

## Equivalence summary

In this admin-guide domain, VantageMap covers the **operational** slice of administration well — user management, roles assignment, technical users/API tokens, tag-group administration (with matching on-the-fly/hybrid/predefined modes), the quality-seal workflow, and a webhook engine — but it covers only a small fraction of LeanIX's **configuration** surface. LeanIX's admin area is fundamentally a meta-model and no-code configuration platform (custom types/fields/relations/subtypes, conditional attributes, per-field permission matrices, custom KPIs, metrics, automations, calculations, dashboards, portals, workspace views), whereas VantageMap's model, permissions, reports, and dashboards are fixed in code. The heaviest, genuinely-core gaps are meta-model configuration and granular permissions; the largest chunks of the remaining guide (automations, calculations, portals, virtual workspaces, SSO, discovery/integrations) are appropriately deferred to PLANV4 rather than counted as MVP parity gaps.
