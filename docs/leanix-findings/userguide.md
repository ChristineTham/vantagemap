# SAP LeanIX User Guide — LeanIX vs VantageMap

**Scope note.** The LeanIX *User Guide* (424 pages, pages 1–424) is the end-user-facing manual covering the entire day-to-day EA workflow: Dashboards (incl. Application Portfolio Management, Fact-Sheet-Owner onboarding, and the customizable Architecture Executive KPI dashboard), the Inventory (fact sheets, subtypes, list/table view + inline editing, import/export via Excel, completeness scoring, subscriptions, quality seal, mandatory attributes, data-quality insights, searching/filtering incl. advanced/strict/lifecycle/subscription filters, tags, archiving), Reports (Landscape, Matrix, Portfolio, Roadmap, Radar, Circle Map, Cost, World Map — all user-configurable with views/clustering/drill-down/URL-parameter state), Diagrams (Free Draw, Data Flow, Lucidchart, templates, versioning), Collaboration (Surveys with campaigns/reminders/CSV/calculated fields, To-Dos, Comments, Architecture Decisions), Workspace Views, Presentations, Collections, the Extension Hub, Notifications, and the User Profile. This is the single richest document for judging core EA-tool feature parity. VantageMap covers the same *domains* but with fixed, non-configurable implementations of each.

## Key gaps

The core parity gaps (excluding advanced/PLANV4 items) cluster into four areas that define what an EA tool *is*:

- **Configurable report engine (rows 29–40).** LeanIX's differentiator is that Landscape, Matrix, Portfolio, Roadmap, Radar, Circle-Map, Cost and World-Map reports are *one interactive engine* with switchable views, clustering, drill-down, layout modes, and per-report save/share/export/URL-state. VantageMap ships a **fixed set of hard-coded reports** covering roughly the same *analyses* (TIME, 6R, obsolescence, coverage, portfolio health) but no report builder, no Landscape heat-map, no Matrix report, no Circle-Map, no World-Map, and no export/share per report. This is the single largest gap.
- **Diagramming (rows 41–46).** Entirely absent. Free Draw, Data Flow, templates, versioning, layers, and diagram-to-inventory linking have no counterpart in VantageMap. Large effort.
- **Dashboards & personalization (rows 1–8).** VantageMap's dashboard is a static page. LeanIX offers a drag-drop panel builder, per-user/default/shared dashboards, global filters, KPI history, and the configurable Architecture Executive KPI dashboard. No panel/favorites/collections model exists.
- **Collaboration depth (rows 49–52).** Surveys, To-Dos, and Comments exist as *basic* records but lack the workflow layer: no survey builder or campaign send/remind/dynamic-scope/CSV, no Approval/Ask-Question to-dos, and @mentions are wired into the backend (schema + notifications) but have no comment-UI picker. Fact-sheet **Resources/attachments** (row 53) and **Mandatory attributes** (row 20) are also missing but load-bearing for LeanIX data-quality governance.

Genuinely close-to-parity areas: Inventory core CRUD, fact-sheet types/subtypes, Quality Seal, Tags, full-text Search + saved searches, Excel/CSV export, audit/update log, and User Profile.

## Equivalence summary

VantageMap covers the same **conceptual surface** as the LeanIX User Guide — inventory of fact sheets, governance (quality seal, tags, subscriptions, surveys, to-dos, comments, audit), search, and a portfolio/strategy/radar/roadmap analytic set — and reaches genuine EQUIVALENCE on the inventory-CRUD, quality-seal, tagging, and search fundamentals. But it lags substantially on the two capabilities the guide spends the most pages on: the **user-configurable interactive report engine** (Landscape/Matrix/Portfolio/Roadmap/Radar/Circle-Map/Cost/World-Map with views, clustering, drill-down, export and URL-state) and **visual diagramming** (Free Draw / Data Flow / templates), both of which are absent or replaced by fixed, non-configurable equivalents. Overall this domain is roughly **40–50% covered**: strong on the data/governance backbone, thin on the interactive-visualization, dashboard-personalization, and collaboration-workflow layers that make LeanIX a self-service EA platform.
