# Business Capability Map (reference BCM) — LeanIX vs VantageMap

## Scope note

This document ([[page 1]], single-page graphic + ~875 lines of extracted labels) is SAP LeanIX's **reference business capability map** — a ready-made, three-level Business Capability Model (BCM) that customers can adopt as a starting taxonomy. It is content, not a feature spec: it presents ~20 Level-1 domains (Asset Management, Human Resources, Omnichannel Commerce, Sales, Enterprise Strategy, Manufacturing, Product Management, Sourcing & Procurement, Supply Chain Planning/Execution/Enablement, Customer Service, Finance, Marketing, R&D/Engineering, GRC, Sustainability Management, Service Delivery, International Trade & Global Tax, Portfolio & Project Management, etc.), each decomposed into Level-2 areas and Level-3 capabilities (hundreds of leaves, e.g. "General Ledger Accounting", "Talent Acquisition", "Demand Forecasting"). The doc's stated purpose ([[page 1]]) is: use a BCM as the "foundational element of enterprise architecture", map applications to named capabilities, and "quickly identify gaps, duplications, and opportunities for modernization." So the reviewable features are: (a) can VantageMap **hold** a multi-level BCM of this shape and scale, and (b) can it **visualise** it as a map with health/heat overlays and app coverage.

## Key gaps

- **Configurable heatmap overlay (#6, #7).** VantageMap shows a single fixed health dot per capability. The core LeanIX value of a BCM view — shading each capability cell by a *chosen* metric (app fit, cost, risk, redundancy, lifecycle) to read the estate at a glance — is not there. This is the most important parity gap for this doc's domain.
- **Coverage/duplication surfaced on the map (#9).** Coverage exists as a standalone bar chart and uncovered count, but it is not painted onto the capability map, and "duplication" (many apps redundantly covering one capability) isn't flagged at all.
- **Interactivity at scale (#12, #15).** A real SAP-scale BCM (hundreds of leaves) needs collapse/expand, search-in-map, and zoom. VantageMap renders the whole tree flat — fine for a demo, awkward for the full reference model.
- **No prebuilt reference taxonomy (#13).** Nothing ships an industry/SAP reference BCM; users build it by hand or via generic import.
- **3-level cap (#4).** The `capabilityLevelEnum` hard-limits depth to 3, adequate for this doc but a ceiling for deeper models.

## Equivalence summary

For the *data model*, VantageMap is essentially EQUIVALENT to what this reference BCM requires: a first-class BusinessCapability entity with a 3-level parent/child hierarchy (Domain/Area/Capability), health, lifecycle, maturity, strategic importance, and app relationships — it can store a map of exactly this shape. The gap is on the *visualisation* side: VantageMap renders a static nested-card map with a single fixed health dot, whereas LeanIX's signature capability-map view is an interactive, configurable **heatmap** you can colour by any metric and read coverage/redundancy from directly. So VantageMap can *represent* this map faithfully but only *partially* visualise it the way LeanIX does — the missing pieces (selectable heat overlay, coverage-on-map, collapse/expand at scale) are moderate-effort UI work on top of an already-adequate schema.
