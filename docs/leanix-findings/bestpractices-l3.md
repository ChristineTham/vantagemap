# Best practices Level 3 Expert — LeanIX vs VantageMap

**Scope note.** This 13-page SAP LeanIX "Best Practices — Level 3 (Expert)" guide is a strategic-adoption playbook rather than a feature manual. It presents three "Recommendations": (1) advanced **use cases** (Transformations / target architecture, Self-Built Software Discovery, AI Governance & Adoption); (2) **SAP LeanIX adoption** as the core of strategic decisions (executive/persona/use-case dashboards, bringing business teams together via SAP Signavio/Toolchain integration, user engagement & adoption measurement); and (3) advanced **governance** mechanisms (Calculations, Custom Integrations, Architecture Decisions). Most items are advanced/expert-tier LeanIX capabilities; several map directly to PLANV4-deferred areas (discovery/connectors, AI governance, transformation/target-state, automation). ## Key gaps

Focusing on core EA-tool parity (excluding the many DEFERRED/PLANV4 use-case items above):

- **Architecture Decisions (ADR) feature (row 13, MISSING, M).** A recognized core EA governance capability — centralized, standardized decision records with an approval flow. VantageMap has no decision entity. The existing Quality Seal state machine (`src/lib/quality-seal.ts`) and comments/subscriptions could be reused, so effort is moderate rather than large.
- **Calculations / derived-field engine (row 11, MISSING, L).** LeanIX auto-populates fields from admin-authored JavaScript. VantageMap's `customFields` jsonb is passive storage with no derivation, no admin config, and no error log. This is genuinely advanced and security-sensitive (sandboxed JS execution), so it is a lower-priority core gap.
- **Configurable executive / per-use-case / per-persona dashboards (rows 6–7, PARTIAL, L/M).** VantageMap ships a single fixed dashboard. LeanIX's differentiator here is user-defined views scoped by segment (org/dept/market) with segment-relevant KPI selection and saved dashboard configs — none of which exist. This overlaps with the broader "configurable report/view builder" gap noted across the LeanIX docs.
- **Adoption / usage analytics (row 9, PARTIAL, M).** Audit logging exists but there is no active-user/consumption analytics or Shared360 equivalent.

## Equivalence summary

For this expert-tier document, VantageMap is only moderately close. The document is dominated by advanced use cases and integrations that map cleanly to PLANV4-deferred scope (Transformations/target-state 15.2, Self-Built Discovery & SBOM & Signavio/Jira connectors 15.6, AI Governance 15.7), so most rows are correctly DEFERRED rather than counted as gaps. Where the doc describes *core* expert governance, VantageMap has real parity on the integration primitives (REST + GraphQL + HMAC webhooks all present) but two genuine feature gaps stand out: **Architecture Decisions/ADRs** (MISSING, most impactful and reusable via the Quality Seal workflow) and **Calculations** (MISSING, advanced and security-sensitive), plus the recurring **configurable/persona dashboards** shortfall (PARTIAL). Net: VantageMap covers the plumbing and as-is analytics of this domain, but lacks the expert-level decision-governance and dashboard-personalization features that define LeanIX's "Level 3" tier.
